# Desktop Pet Mascot 🎀

Một ứng dụng Desktop Pet dễ thương chạy vòng quanh màn hình Windows, được xây dựng bằng Python và PyQt5.

## ✨ Tính năng
- 🌸 Nhân vật Chibi Anya tương tác trực tiếp trên Desktop.
- 🏃 Tự động đi dạo, dừng nghỉ, rơi trọng lực và va chạm mép màn hình.
- 🖱️ Tương tác chuột:
  - **Kéo thả (Drag & Drop)**: Nhấc pet lên và thả rơi tự do.
  - **Bấm chuột (Click)**: Biểu cảm hào hứng Waku Waku kèm hiệu ứng âm thanh.
  - **Chuột phải (Right-Click Menu)**: Bật/tắt âm thanh, thoát ứng dụng.
- 🎨 Đồ họa trong suốt không viền (Translucent Frameless Overlay).

## 🚀 Cài đặt & Chạy

### 1. Cài đặt thư viện:
```bash
pip install -r requirements.txt
```

### 2. Chạy ứng dụng:
```bash
python main.py
```

### 3. Đóng gói thành file .exe:
```bash
pyinstaller DesktopPet.spec
```
